# Frontend FSD structure

This frontend is organized around Feature-Sliced Design layers:

- `src/app` - application bootstrap, root component, global styles
- `src/pages` - route-level screens
- `src/shared` - reusable assets, utilities, and UI primitives

## Scripts

- `npm run dev` - start the Vite dev server
- `npm run build` - type-check and build for production
- `npm run lint` - run ESLint
