# 🛡️ Anti-Scam Trainer

Интерактивный тренажёр безопасных сделок для пользователей Avito. Кейс 5 хакатона **Avito Start**.

## Проблема

На классифайдах пользователи договариваются о сделках напрямую и сталкиваются с типовыми схемами мошенничества: переход в сторонние мессенджеры, фишинговые ссылки на «безопасную оплату», запрос кода из SMS, предоплата вне платформы. Платформа может бороться с мошенничеством технически, но часть безопасности всегда зависит от решений самого пользователя — и обычные текстовые инструкции работают хуже, чем практика.

## Решение

Веб-приложение — интерактивный тренажёр, в котором пользователь выбирает роль (покупатель/продавец), проходит реалистичные диалоговые сценарии сделок, принимает решения в спорных моментах и получает объяснение последствий каждого выбора — не просто «правильно/неправильно», а почему решение повышает или снижает риск.

## Быстрый старт

### Через Docker Compose (рекомендуется — поднимает весь стек)

1. Скопируй `.env.example` в `.env` и заполни значения:
   ```bash
   cp .env.example .env
   ```
2. Подними:
   ```bash
   docker compose up --build -d
   ```
3. Открой:
   - Frontend: http://localhost:3000
   - Backend health-check: http://localhost:18080/health

4. Останови:
   ```bash
   docker compose down
   ```

### Backend отдельно (для разработки)

```bash
docker compose up postgres -d
cd backend
go run ./cmd/api --config config.yaml
```

### Frontend отдельно
*[ЗАПОЛНИТЬ: команды запуска фронтенда в dev-режиме]*
```bash
cd frontend
npm install
npm run dev
```

|---|---|---|
| POST | `/api/v1/auth/register` | Регистрация |

## Особенности реализации

- **Сессии** — opaque-токены (UUID) в HttpOnly cookie, не JWT: логаут = удаление записи из БД, простая инвалидация.
- **Пароли** — bcrypt, минимум 8 символов.
- **Восстановление пароля** — одноразовый криптографически случайный токен (`crypto/rand`), хранится в БД только в виде SHA-256 хэша, TTL 1 час.
- **CORS** — явный allowlist origin'ов с `Access-Control-Allow-Credentials`, без wildcard (требование безопасности при работе с cookie).
